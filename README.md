# 汪汪队资金看板

20 只代表性宽基 ETF 每日申赎净流入看板，全部用公开数据自算：上交所 / 深交所每日 ETF 份额 + 腾讯行情。

口径：净流入 = Σ(当日份额 − 前一交易日份额) × 当日收盘价（亿元），份额拆分/合并已自动修正。每个交易日北京时间早上更新。

仅供研究自用，不构成投资建议。

## 脚本（scripts/）

在同一目录下按顺序运行（Python 3，仅用标准库 + 公开接口）：

1. `fetch.py`：腾讯日K（成交量、收盘价）+ 上交所 ETF 每日份额。
2. `fetch_sz.py`：深交所 ETF 每日份额。
3. `snap.py`：腾讯 qt.gtimg.cn 最新行情快照（需先有一个旧快照文件作为模板）。
4. `build2.py`：计算净流入 = Σ(当日份额 − 前日份额) × 当日收盘价（亿元），自动识别份额拆分/合并，输出 dashboard.json 与 CSV。

份额由交易所 T+1 公布。仅研究自用，非投资建议。
